# Pavan Kumar Prajapati — Personal Portfolio Website

A responsive personal portfolio website created using **HTML5 and CSS3** for the HTML & CSS internship project.

## Project Overview

The website presents my profile as a B.Tech Computer Science Engineering student and showcases my education, technical skills, projects, academic achievements, certifications, and contact details.

## Technologies Used

- **HTML5** — page structure and content
- **CSS3** — styling, layout, colors, hover/focus effects, and responsive design
- **CSS Grid and Flexbox** — page and component layouts
- **Media queries** — adapting the layout to smaller screens

No JavaScript, React, Bootstrap, backend, or database is used in this project.

## Files and Folders

```text
Web Internship/
├── index.html                  # Main portfolio page
├── style.css                   # Website styling and responsive rules
├── myphoto.png                 # Profile photo used by the website
├── Project Description.txt     # Short project description for submission
└── ScreenShot/
    ├── Desktop.jpg             # Desktop website screenshot
    └── Mobile.jpg              # Mobile website screenshot
```

Keep `index.html`, `style.css`, and `myphoto.png` together in the same folder. The HTML file refers to the photo as `myphoto.png`, so do not move it into another folder unless you also update the image path in `index.html`.

## How to Run the Website

1. Extract the ZIP file.
2. Open the `Web Internship` folder in Visual Studio Code or another code editor.
3. Open `index.html` in a web browser. You can also use the Live Server extension in Visual Studio Code if it is installed.
4. Check the navigation and view the website at both desktop and mobile screen sizes.
